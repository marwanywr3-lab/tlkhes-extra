# مساعد المستندات الذكي (Document AI Assistant)

واجهة ويب حديثة وهادئة (Warm Minimalist) تتيح رفع ملفات PDF، الصور، أو النصوص لتحليلها وتلخيصها واستخراج المعلومات منها فوراً، مع روبوت دردشة تفاعلي لمناقشة المحتوى أو التعديل على الملخص باستخدام واجهات برمجة تطبيقات Google AI Studio (Gemini 2.5 Flash و Flash Lite).

---

## المميزات الرئيسية

- **رفع سحب وإفلات مرن:** دعم ملفات PDF والصور (PNG, JPG, WEBP) والنصوص المباشرة مع معاينة الملف.
- **تحليل وتلخيص تنفيذي احترافي:** استخراج الأهداف، المحاور الأساسية، الأرقام المؤثرة، والتوصيات بتنسيق Markdown أنيق.
- **مساعد دردشة تفاعلي مستمر:** يمكنك الاستفسار عن أي بند داخل المستند أو طلب إعادة صياغة الملخص.
- **اختيار النموذج:** التبديل الفوري بين `Gemini 2.5 Flash` و `Gemini 2.5 Flash Lite`.
- **خصوصية وأمان تام:** يعمل الموقع بنظام Client-side كامل؛ يُحفظ مفتاح الـ API في متصفحك الشخصي عبر `localStorage` دون رفعه إلى أي خادم وسيط.
- **تصميم دافئ ومتجاوب:** باليتة ألوان هادئة ومريحة للعين، ومتجاوبة تماماً مع مختلف أحجام الشاشات.

---

## متطلبات التشغيل

1. متصفح ويب حديث (Google Chrome, Safari, Edge, Firefox).
2. مفتاح مجاني لـ API من [Google AI Studio](https://aistudio.google.com/).
